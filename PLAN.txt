===============================================================================
 VOICE + GESTURE CONTROL  -  PRODUCT PLAN  (plan.txt)
===============================================================================
Goal: turn voice_app.py + hand_cursor.py into a polished hands-free "digital
assistant" that feels natural: talk to it, reach toward the screen to use the
mouse, and let it handle routine computer tasks.

STATUS: v5.3 works end-to-end (voice, waveform UI, timers, clipboard history,
screen vision, cursor vision, Gemini memory, TTS voice profiles, click beeps,
log persistence, autostart, math, notes, sites, power, reach-gated air cursor,
live tuning, chained commands, wake word aliases, timer toast popups,
clipboard manager GUI card, live calibration size feedback, gesture trainer
window, system tray + minimize-to-tray + global hotkey restore, draw-macro
gestures that trigger actions).

------------------------------------------------------------------------------
1) CURRENT ARCHITECTURE (v5.3)
-------------------------------------------------------------------------------
- voice_app.py   ~3400 lines : tkinter GUI + controller.
  Threads:  "stt"    (speech -> text, Google Web API)
            "tts"    (pyttsx3 speak queue)
            "timers" (reminder fire loop)
  GUI thread: clipboard watcher, waveform meter, hand preview, log,
              hand-size calibration sampler.
  Config: voc_config.json (gitignored - holds Gemini key + device index).
  Modules/cards: VOICE (device/lang/AUTO-BEST/start-stop), WAVEFORM,
                 HAND CURSOR (start/stop/cam/preview/SENS slider/SCROLL
                 slider/CALIBRATE REACH + live size readout + TRAIN
                 GESTURES), HEARD banner, CLIPBOARD card (click-to-paste
                 list), ACTIVITY LOG, status bar.
  Tray: pystray icon + "Show/Hide" + "Quit" menu; X button hides to tray
        (first time a hint is logged); global hotkey ctrl+alt+v restores
        the window; vocal "minimize to tray" / "show window" work too.
Command branches: app launch, browser, window, system keys, volume,
   text, search, type, timer/reminder, clipboard, screen vision, cursor
   vision, Gemini memory ("clear my memory"), time/date, notes, calculator,
   site shortcuts, power, autostart, gestures, "open app", Gemini Q&A.
   TTS profiles (voice + Speed slider), click-beep toggles, autostart
   checkbox. Every log line is also written to voc_log.txt (capped).
   v5.3: DRAW MACROS - button (or voice "draw macros") switches the hand
   engine to macro mode; a $1-style recognizer classifies the fingertip
   stroke (circle, v, check, l, s, z, w, line, slash) when the finger
   stops ~1 s or leaves the frame; the mapped action then runs like a
   normal voice command (remappable via macro_actions config).
   v5.2: gesture trainer, tray (+ hotkey), training voice commands.
   (v5.1: chained "then" commands; wake word aliases; timer toasts;
   clipboard click-to-paste card; calibration live size readout.)

- hand_cursor.py : MediaPipe hand engine (daemon thread).
  v1.6: DRAW MACROS - driver mode "macros" (set_mode) plus a built-in
        $1-style stroke recognizer (_recognize_macro + MACRO_TEMPLATES).
        Emits ("macro", name)/(("macro", None); never drives the mouse
        while drawing; dwell (commits after ~1 s still) or hand-lost
        finalizes the stroke. preview overlay + finger panel keep working.
  v1.5: TRAINING MODE - set_training(True) stops ALL mouse driving and
        instead emits "train" events (raw pose, stable flag, fingers,
        size, armed) for the GUI pass/fail trainer; preview overlay and
        finger panel keep working.

- hand_cursor.py : MediaPipe hand engine (daemon thread).
  v1.6+: DRAW MACROS (driver mode "macros", $1-style stroke recognizer;
         "mac" + "train" mode via set_mode/set_training); REACH GATE
         (set_reach_thresholds; live size events); hysteresis pinch and
         stable pose debounce; emits "beep" events (left/right/drag).
   Gestures: index/open = move, pinch = click/drag, peace = scroll,
             three fingers = right-click/drag, fist = drag.
   Never touches the GUI: pushes events through on_event/on_preview queue.

2) VISION - "ONE-COMMAND COMPUTER"  (roadmap)
------------------------------------------------------------------------------
PHASE A - STABILITY & COMFORT  (mostly DONE in v4.2 / v5.0)
  [x] Calibration UI: two-phase wizard (rest hand, then reach toward screen)
      writes ARM_SIZE/DISARM_SIZE into voc_config.json (per-user distance).
  [x] Sensitivity slider wired live (engine.set_sensitivity, no restart).
  [x] Scroll-speed slider wired live (engine.set_scroll_speed, no restart).
  [x] Camera picker lists available_cameras() instead of fake "0..5".
  [x] Click confirmation sound (beep on recognised click/drag) - v5.0.
  [x] Reach/dwell visual feedback during calibration: live "size X.XX
      (REST/REACH)" readout in the HAND CARD - v5.1.
  [x] Gesture training window with live pass/fail: TRAIN GESTURES button
      (or "train gestures" voice command) - engine pauses the mouse and
      lights each pose green once held ~0.2 s - v5.2.

PHASE B - SMARTER ASSISTANT
  [x] Wake word ("hey vo" / "ok vo" / "wake up vo") to arm mic hands-free - v5.1.
  [x] On-demand cursor vision: "what's under my cursor" (region grab) - v5.0.
  [x] Multi-step commands chained: "open chrome then search weather" - v5.1.
  [x] Gemini memory: short conversation context retained per session,
      "clear my memory" resets it - v5.0.
  [x] Voice profiles for TTS: voice dropdown + rate slider in GUI - v5.0.

PHASE C - SYSTEM DEEP INTEGRATION (Windows)
  [x] System tray icon + minimize-to-tray (X hides, click tray/hotkey
      restores, tray Quit really exits) - v5.2.
  [x] Timer finished = always-on-top toast popup (click to dismiss) - v5.1.
  [x] Clipboard manager GUI card (click entry to paste) - v5.1.
  [x] Auto-start on boot option (registry HKCU Run key) - v5.0.
  [x] Activity log persistence to voc_log.txt (capped) - v5.0.

PHASE D - GESTURE X / PRODUCTISATION
  [ ] Two-hand support (left = pointer, right = modifiers).
  [ ] Virtual touchpad mode: hand mapped to a trackpad region.
  [x] Gesture macros: draw a letter/shape to trigger app actions.
      Circle/V/check/L/S/Z/W/line/slash -> lock screen, new tab, copy,
      minimize, settings, close tab, play or pause, mute, maximize.
      $1-style recognizer in hand_cursor; DRAW MACROS toggle + voice.
      Actions are normal voice commands (macro_actions config to remap). - v5.3.
  [ ] Installer (PyInstaller single exe) + auto-update check.
  [ ] Packaging: signed build, first-run wizard, privacy notice.
