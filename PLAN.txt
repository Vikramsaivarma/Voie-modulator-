===============================================================================
 VOICE + GESTURE CONTROL  -  PRODUCT PLAN  (plan.txt)
===============================================================================
Goal: turn voice_app.py + hand_cursor.py into a polished hands-free "digital
assistant" that feels natural: talk to it, reach toward the screen to use the
mouse, and let it handle routine computer tasks.

STATUS: v4.2 works end-to-end (voice, waveform UI, timers, clipboard history,
screen vision, math, notes, sites, power, reach-gated air cursor, live tuning).

------------------------------------------------------------------------------
1) CURRENT ARCHITECTURE (v4.2)
------------------------------------------------------------------------------
- voice_app.py   ~2400 lines : tkinter GUI + controller.
  Threads:  "stt"    (speech -> text, Google Web API)
            "tts"    (pyttsx3 speak queue)
            "timers" (reminder fire loop)
  GUI thread: clipboard watcher, waveform meter, hand preview, log,
              hand-size calibration sampler.
  Config: voc_config.json (gitignored - holds Gemini key + device index).
  Modules/cards: VOICE (device/lang/AUTO-BEST/start-stop), WAVEFORM,
                 HAND CURSOR (start/stop/cam/preview/SENS slider/SCROLL
                 slider/CALIBRATE REACH), HEARD banner, ACTIVITY LOG,
                 status bar.
  Command branches: app launch, browser, window, system keys, volume,
  text, search, type, timer/reminder, clipboard, screen vision, time/date,
  notes, calculator, site shortcuts, power, gestures, "open app", Gemini Q&A.

- hand_cursor.py : MediaPipe hand engine (daemon thread).
  v1.3: REACH GATE - cursor only arms when your hand is CLOSE to the screen
        (per-user ARM_SIZE/DISARM_SIZE with hysteresis; CALIBRATE REACH in
        the GUI writes per-user values to voc_config.json). STABLE_FRAMES
        (5) debounce stops one-frame flickers. Pinch hysteresis
        (ENGAGE=0.28/RELEASE=0.55). Ambiguous poses (middle-only, thumbs-up)
        fall back to MOVE, never a button. Emits live hand_size samples so
        the app can calibrate. Live set_sensitivity/set_scroll_speed/
        set_reach_thresholds work without restarting.
  Gestures: index/open = move, pinch = click/drag, peace = scroll,
            three fingers = right-click/drag, fist = drag.
  Never touches the GUI: pushes events through on_event/on_preview queue.

2) VISION - "ONE-COMMAND COMPUTER"  (roadmap)
------------------------------------------------------------------------------

  [x] Calibration UI: two-phase wizard (rest hand, then reach toward screen)
      writes ARM_SIZE/DISARM_SIZE into voc_config.json (per-user distance).
  [x] Sensitivity slider wired live (engine.set_sensitivity, no restart).
  [x] Scroll-speed slider wired live (engine.set_scroll_speed, no restart).
  [x] Camera picker lists available_cameras() instead of fake "0..5".
  [ ] Click confirmation sound (beep on recognised click/drag).
  [ ] Reach/dwell visual feedback on the overlay while calibrating.

PHASE B - SMARTER ASSISTANT
  [ ] Wake word ("hey vo") to arm mic without a global hotkey.
  [ ] On-demand screen vision: "what's under my cursor" (region grab).
  [ ] Multi-step commands chained: "open chrome then search weather".
  [ ] Gemini memory: short conversation context retained per session.
  [ ] Voice profiles for TTS: rate/pitch/voice selectable in GUI.

PHASE C - SYSTEM DEEP INTEGRATION (Windows)
  [ ] System tray icon + minimize-to-tray; global hotkey to re-open.

  [ ] Clipboard manager GUI card (click entry to paste).
  [ ] Auto-start on boot option (registry Run / startup folder).
  [ ] Activity log persistence to voc_log.txt.

PHASE D - GESTURE X / PRODUCTISATION
  [ ] Two-hand support (left = pointer, right = modifiers).
  [ ] Virtual touchpad mode: hand mapped to a trackpad region.
  [ ] Gesture macros: draw a letter/shape to trigger app actions.
