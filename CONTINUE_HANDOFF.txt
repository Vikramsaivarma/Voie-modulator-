3) CURRENT ARCHITECTURE (v5.5.0)
===============================================================================
- voice_app.py ~3600 lines: tkinter GUI + controller. Threads: stt, tts,
  timers. GUI thread: clipboard watcher, waveform meter, hand preview, log,
  calibration sampler, tray. Config voc_config.json (gitignored).
  Cards: VOICE, WAVEFORM, HAND CURSOR (SENS/SCROLL sliders, CALIBRATE REACH
  + live size readout, TRAIN GESTURES, DRAW MACROS, TOUCHPAD, Beep), HEARD
  banner, CLIPBOARD card (click-to-paste), ACTIVITY LOG, status bar.
  Tray (pystray) + hotkey ctrl+alt+v + X-button hides to tray; real shutdown
  is on_close() guarded by self._closing.
  Thread-safety (v5.5.0): _gui_call() marshals worker->GUI work to the
  event queue so voice, tray, hotkey and engine threads can never touch Tk
  directly; _append_log is worker-safe (posts back to GUI thread when called
  from a worker); hand-engine callbacks carry an epoch captured at start()
  so stale events from a previous engine are dropped before reaching the UI.
  Mode logic (5.4): driver modes are mutually exclusive -
    macros (DRAW MACROS config macro_mode/macro_actions)
    touchpad (TOUCHPAD config touchpad_mode/touchpad_gain)
    cursor (default). Whichever is enabled last wins (both sides enforce it).
  Chaining: static VoiceControlApp._parse_chain(lowered) splits on
  \s+(?:and\s+)?then\s+; parts need >=2 words or a single-word verb in
  (start, stop, help, refresh, minimize, maximize, mute, enter, undo, paste,
  copy); else None (Gemini fallback). Worker executes parts, 0.6s between.
  Draw macros: engine emits ("macro", name); GUI _on_macro maps name ->
  action (MACRO_DEFAULT_ACTIONS, overridable via macro_actions config) and
  runs it via handle_command on a daemon thread.

- hand_cursor.py: MediaPipe engine (daemon). Landmark constants defined.
  v1.8.0 engine-correctness + safety fixes (spiral 1): _reset_gesture_state
  helper resets mode/candidate/pinch on disarm/loss/training; _press_button
  guards on running+training; macro mode uses _macro_armed stroke-in-progress
  flag (no idle ('macro', None) echo, no merged interrupted strokes);
  start()/stop() serialised on _lifecycle_lock; _stop_locked keeps thread
  ref for reaper; _run releases on open failure + tolerates transient bad
  reads, 640x480 + 1-frame buffer; every exit path emits 'stopped'.
  Camera-lifecycle fixes carried over from v1.7.1 (stop() force-releases
  capture, start() reaps stale threads).
  Driver modes (set_mode):
    "cursor"  - absolute mapping _to_screen + reach gate (arm/disarm,
                hysteresis), STABLE_FRAMES=5 debounce, pinch hysteresis,
                ambiguous poses fall back to MOVE.
    "macros"  - _handle_macro collects fingertip path; dwell (~1s still)
                or hand-lost finalizes; _recognize_macro is a $1-style
                matcher (resample 32 -> normalize to 0..1 -> template
                distance; MACRO_MATCH_MAX=0.22); 9 templates (circle, v,
                check, l, s, z, w, line, slash). MACRO_MIN_POINTS=12 gate
                lives in _finalize_macro (short strokes -> macro None).
    "touchpad"- _handle_landmarks; _touchpad_next returns relative
                cursor from wrist+middle-MCP center deltas, EMA smoothing
                (TOUCHPAD_SMOOTH 0.35), noise floor 0.0015, clamp 0.04,
                gain = sensitivity*TOUCHPAD_GAIN(2.5). Reach gate skipped.
  Events: log/status/hand_state/hand_preview/hand_size/started/stopped/
  error/train/macro/beep/tts_voices/quit. Engine never touches the GUI.
