================================================================================
VOICE CONTROL - QUICK START GUIDE  (v5.3)
===============================================================================

A Windows desktop app that lets you control your PC with your voice.
Modern dark-themed GUI, live voice-activity WAVEFORM, Google speech-to-text,
offline voice feedback (pyttsx3), a "what the app heard" display,
Gemini-powered answers + SCREEN VISION + CURSOR VISION (region grab),
Gemini SESSION MEMORY, TTS voice profiles (voice + speed), AUDIBLE CLICK
BEEPS, AUTO-START on login, ACTIVITY LOG saved to voc_log.txt, TIMERS/
REMINDERS (with toast popups), CLIPBOARD HISTORY (with a click-to-paste
card), CHAINED COMMANDS ("open chrome then search weather"), WAKE WORD
("hey vo"), SYSTEM TRAY icon with minimize-to-tray and a global hotkey
(ctrl+alt+v) to bring the window back, a GESTURE TRAINER window with live
pass/fail feedback for every hand pose, DRAW-MACRO GESTURES that run
actions by tracing shapes in the air, AUTO-BEST microphone selection,
and a HAND-CURSOR air mouse: use your webcam to move the pointer and
"touch" the screen with finger gestures (with a live 5-finger state panel
on the preview).

--------------------------------------------------------------------------------
1) REQUIREMENTS
--------------------------------------------------------------------------------
  * Windows 10 or Windows 11 (64-bit recommended)
  * Python 3.11 or newer from:  https://www.python.org/downloads/
      IMPORTANT: during Python installation, tick the box
      "Add Python to PATH" (it is off by default).
  * A working microphone.

--------------------------------------------------------------------------------
2) INSTALL - RUN install.bat
--------------------------------------------------------------------------------
  1. Put all files in the SAME folder:
       voice_app.py
       requirements.txt
       install.bat
       QUICK_START.txt
       voc_config.json   (created automatically - your settings live here)
  2. Double-click install.bat (or right-click -> Run as administrator).
  3. The script detects Python, upgrades pip, installs every dependency,
     verifies all imports and shows "INSTALLATION COMPLETE".
  4. Fix any [ERROR] printed on screen, then re-run install.bat.

--------------------------------------------------------------------------------
3) START THE APP
--------------------------------------------------------------------------------
  In Command Prompt (cmd) in the app folder:

       python voice_app.py

...or double-click voice_app.py. Use "py" instead of "python" if the
   latter is not in PATH.

   The webcam hand-cursor starts automatically when the app opens. If you
   do not want it, press STOP in the HAND CURSOR row (or say it later).

   Allow microphone access when Windows asks
   (Settings -> Privacy & security -> Microphone -> ON).
   Also allow Camera access for the hand cursor
   (Settings -> Privacy & security -> Camera -> ON).

--------------------------------------------------------------------------------
4) PICK THE RIGHT MICROPHONE  (IMPORTANT!)
--------------------------------------------------------------------------------
By default Windows may pick a noisy or acoustic microchip. If the app
   "does not listen" or hears only background noise:

   1. Click START LISTENING once, then STOP.
   2. Press AUTO-BEST - the app measures every microphone, logs the quiet
      level of each one, and automatically selects the quietest usable
      input. This is the quickest way to get a good microphone.
   3. The LIVE waveform bar under the settings shows your voice level in
      real time (green when quiet, amber approaching speech level, RED and
      taller while you talk). The header badge flips to SPEAKING. Speak now
      and check it moves.
   4. The "Heard:" line shows the last thing the app understood.
   5. You can still pick any entry manually from the "Microphone:" dropdown
      and use TEST MIC (shows the noise level and transcribes a sample).
   6. The choice is saved in voc_config.json automatically.

  Troubleshooting guides for more issues are in section 7.

--------------------------------------------------------------------------------
5) GEMINI AI ANSWERS
--------------------------------------------------------------------------------
  Any phrase that is not a known command is sent to Google Gemini and the
  answer appears in the app log (a short version is also spoken aloud).

  * The API key is already stored in voc_config.json ("gemini_api_key").
  * You can also use the GEMINI_API_KEY environment variable instead.
  * To change the AI model, edit "gemini_model" in voc_config.json
    (current default: gemini-3.6-flash).
  * If the key stops working, request a free one at:
        https://aistudio.google.com/apikey
    and paste it into voc_config.json.

  Example usage:
      "Ask what is the capital of France"
      "What is 15 percent of 240"
      "How do I clear my browser cache"
      Or simply: "Tell me a fun fact"

  SCREEN VISION (ask Gemini to look at your screen):
      "Analyze screen" / "What is on my screen"
      "Describe what is on my screen"
      "Read my screen and summarize it"
   -> The app captures a screenshot, sends it to Gemini, shows the answer
      in the log and reads a short version aloud.

  CURSOR VISION (look under the mouse pointer):
      "What is under my cursor" / "Under my mouse" / "Describe the cursor region"
   -> The app captures a region around the mouse pointer and Gemini
      describes what is there - perfect for reading tooltips/small text.

  GEMINI SESSION MEMORY:
      The last few question/answer turns are kept as conversation context,
      so follow-ups like "and what about the second one?" work.
      "Clear my memory" / "Forget" resets that context.

  TTS VOICE PROFILE:
      Use the "Voice:" dropdown (Windows SAPI5 voices, discovered live on
      first speech) and the "Speed:" slider in the MICROPHONE & VOICE card.

TIMERS & REMINDERS:
       "Set a timer for 5 minutes"
       "Set a timer for 1 hour 30 minutes"
       "Remind me in 10 minutes to stretch"
    -> When the time is up the app pops a small always-on-top toast
       (click it to dismiss) and speaks the reminder.

   CHAINED COMMANDS:
       "Open chrome then search the weather"
       "Open notepad and then press enter"
       "Type hello then press enter"
    -> Commands split on " then " / " and then " and run one after the
       other (about 0.6 s apart). A question that merely contains "then"
       (for example "what came first then why") goes to Gemini instead.

   WAKE WORD:
       "Stop Listening" pauses the mic. Re-arm it hands-free with:
       "Hey vo"   "OK vo"   "Wake up vo"   "Hi vo"   (or "Start Listening")

   CLIPBOARD CARD:
       The GUI shows your last few copied entries. Click any row to paste
       it into the focused window.
       "What did I copy"    "Show my clipboard"   -> spoken + log list.

6) AIR CURSOR / HAND CONTROL (webcam "touch")
-------------------------------------------------------------------------------
The HAND CURSOR row in the app turns your webcam into an air mouse:

  GESTURE                ACTION
  -----------            -----------------------------------------------
  Index finger up        Move the cursor
  Open hand (5 fingers)  Move the cursor too (wider range, easier to hold)
  Pinch (thumb+index)    Click / tap (hold it to drag)
  Peace sign             Scroll (move your hand up or down)
  3 fingers              RIGHT click / right-drag (context menus)
  Fist                   Hold the LEFT mouse button (drag/select)

  * The HAND CURSOR row has live tuning controls:
      Sens slider  -> pointer speed/mapping (1.0 = full frame, raise to zoom)
      Scroll slider-> how fast the peace sign scrolls
      Beep box     -> audible confirmation tone on every click / drag
      TRAIN GESTURES -> opens the live PRACTICE WINDOW: while it is open
      the mouse is paused and every pose lights up green the moment your
      hand holds it for about 0.2 s (MOVE, CLICK, SCROLL, RIGHT CLICK,
      DRAG). Say "close gesture trainer" when done.
      CALIBRATE REACH -> two-phase wizard (rest your hand, then reach toward
      the screen) that writes your personal ARM/DISARM reach thresholds into
      voc_config.json so the cursor ignores a hand resting on your lap.
      While it runs, a live readout next to the button shows your current
      hand size and which pose is being measured: "size 0.31 (REST)" or
      "size 0.52 (REACH)".
      DRAW MACROS -> toggles the hand engine into macro drawing mode. While
      ON, move your index finger in the air to draw a shape; when you stop
      moving for about 1 second or your hand leaves the camera view, the
      shape is recognised and its mapped action runs like a voice command.
      Shapes and their default actions (remappable via macro_actions config):
        circle = lock screen       v     = new tab
        check  = copy              l     = minimize
        s      = open settings     z     = close tab
        w      = play or pause     line  = mute
        slash  = maximize
      Say "draw macros" / "stop macros" to toggle by voice, or press the
      DRAW MACROS button.

  * RAISE-GATED cursor (v1.5): the cursor only controls the mouse while your
    hand is CLOSE to the screen. Rest your hand on your lap or near the
    keyboard and it does NOTHING - no ghost moves, no ghost clicks. Reach
    toward the screen to arm it; bring it closer still to hover/click.

  * The live preview overlay shows a 5-finger panel (T I M R P - thumb,
    index, middle, ring, pinky) that turns green on each finger that is
    extended, so you always see what the app is reading.

  * Starts automatically when the app opens. Use START / STOP to switch.
  * Say "start hand cursor" or "stop hand cursor" to do it by voice.
  * Pick the correct webcam with the "Cam:" dropdown (lists only cameras
    that are actually available) if nothing moves.
  * Untick "Preview" to hide the small camera view and use less CPU.
  * Raise ONE hand facing the camera, about arm's length away. Silhouette
    it against your face/body for steadier tracking.
  * Keep a hand resting visible while clicking - moving it fully away
    releases the button after about half a second.

  Fine tuning lives in voc_config.json:
    camera_index        which webcam (0 = first)
    hand_sensitivity    zoom of the pointer mapping (1.0 = full screen)
    hand_scroll_speed   how fast the peace sign scrolls
    hand_arm_size       reach-gate threshold from CALIBRATE (or None)
    hand_disarm_size    reach-gate threshold from CALIBRATE (or None)
    hand_mode           "on" = webcam starts with the app, "off" = manual
    click_beep          true/false = audible click/drag confirmation tones
    voice_rate          TTS reading speed (80-320, 180 default)
    voice_id            Windows SAPI5 voice id ("" = default)
    autostart           true/false = start the app when you sign in
    minimize_to_tray    true/false = X hides to tray ("" still quits if no tray)
    tray_hotkey         global key combo that restores the window (default
                        ctrl+alt+v; empty disables the hotkey)
    macro_mode          true/false = start the hand engine in DRAW-MACRO mode
    macro_actions       object of shape->action overrides, e.g.
                        {"circle": "shut down the computer"}

8) TROUBLESHOOTING
--------------------------------------------------------------------------------
  * App does not listen / "Could not recognize that speech" all the time
      -> See section 4. Switch microphones in the app dropdown and TEST.
      -> High background noise raises the threshold. Move to a quieter
         spot, or pick the quietest mic from the list.

  * "No speech detected" repeatedly
      -> You are speaking too quietly, or the wrong mic is selected.
      -> Use AUTO-BEST, then watch the live GREEN level bar while you
         talk - it should jump up every time you speak.

  * "Missing Dependencies" dialog on start
      -> Run install.bat (or:  pip install -r requirements.txt).

  * 'python' is not recognized in cmd
      -> Use "py voice_app.py", or reinstall Python with "Add to PATH".

  * PyAudio fails to install
      -> Install the matching wheel for Python 3.11 from:
             https://www.lfd.uci.edu/~gohlke/pythonlibs/#pyaudio
         e.g.  PyAudio-0.2.14-cp311-cp311-win_amd64.whl
         then:  pip install <downloaded file>

  * "Network error" in the log
      -> Google speech recognition needs internet. Check connection and
         just keep talking - the app retries automatically.

  * Gemini answers show an error
      -> Check voc_config.json has a valid "gemini_api_key".
      -> Check "gemini_model" matches one currently offered by Google.
      -> Check internet access. Errors are shown in the log.

  * Types / searches in the wrong window
      -> Focus the right window BEFORE saying "Type ..." / "Search ...".

* "Open Chrome" does nothing
      -> Chrome is installed somewhere unusual. Edit APP_PATHS at the top
         of voice_app.py to point at your install location.

  * Hand cursor: "hand: error" or "camera could not be opened"
      -> Another app (Zoom, Chrome) is using the webcam. Close it.
      -> Try a different "Cam:" number and press START.
      -> Allow Camera access: Settings -> Privacy & security -> Camera.

  * Cursor does not move / is very jumpy
      -> Stay arm's length from the camera, hand silhouette clear of the
         background, facing the lens.
      -> Use the Preview to check the app can see you.
      -> Lower hand_sensitivity in voc_config.json and restart.

  * No dart / click happens on pinch
      -> The pinch threshold is tuned for a relaxed thumb+index touch.
         Make sure the two fingertips actually touch.

  * Webcam keeps turning off or app is slow
      -> Untick Preview (less conversion work), close other camera apps,
         and drop the webcam resolution if you can.

  * Settings changes are lost after closing
      -> voc_config.json is saved automatically next to the app. Make
         sure the app folder is writable and not read-only.
